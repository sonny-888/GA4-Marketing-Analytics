# KPI dictionary

Every measure the dashboard pages show: what it means, its caveats, its format and its exact DAX. Generated by `dashboard/build_pbip.py` from the model itself, so it always matches the dashboard. All other measures (helpers, colours, previous-period values) are in [`measures.dax`](measures.dax).

## Overview

| KPI | What it means | Caveat | Format |
|---|---|---|---|
| **Revenue** | Sum of deduplicated order revenue (USD). | 26 to 31 Jan under-recorded: order values missing. | USD, whole |
| **Orders** | Count of deduplicated orders (by transaction ID, or session + amount + basket when the ID is missing). | Range 4,451 to 5,357 depending on how the 906 ID-less purchases are treated; 5,288 with the project's rule. | Whole number |
| **Sessions** | Count of GA4 sessions (user + session ID). |  | Whole number |
| **Conversion Rate** | Orders ÷ sessions, all days. | Not the same as the funnel's 'sessions with a purchase' (1.35%). | Percent, 2 dp |
| **Revenue Change** | Change vs the previous period of the same length, as text with ▲ or ▼; one per KPI. | Blank ('No prior period') when the selection starts on 1 Nov. | Text |
| **Attributed Revenue** | Revenue credited to each channel by the selected attribution model (default: last click, self-referrals removed). |  | USD, whole |
| **Revenue per Clean Day** | Revenue ÷ days, counting only days with recorded order values. | Excludes 26 to 31 Jan. | USD, whole |

**Revenue**

```dax
SUM ( fct_orders[purchase_revenue_usd] )
```

**Orders**

```dax
COUNTROWS ( fct_orders )
```

**Sessions**

```dax
COUNTROWS ( fct_sessions )
```

**Conversion Rate**

```dax
DIVIDE ( [Orders], [Sessions] )
```

**Revenue Change**

```dax
VAR _cur = [Revenue]
VAR _pp = [Revenue PP]
RETURN
    IF (
        ISBLANK ( _pp ),
        "No prior period",
        IF ( _cur >= _pp, "▲ ", "▼ " ) & FORMAT ( ABS ( DIVIDE ( _cur - _pp, _pp ) ), "0.0%" ) & " vs previous period"
    )
```

**Attributed Revenue**

```dax
VAR _model = SELECTEDVALUE ( dim_attribution_model[model], "last_click" )
RETURN
    IF (
        _model = "markov",
        SUM ( attribution_markov[revenue_usd] ),
        CALCULATE ( SUM ( fct_attribution_credits[revenue_credit_usd] ), dim_attribution_model[model] = _model )
    )
```

**Revenue per Clean Day**

```dax
DIVIDE ( CALCULATE ( [Revenue], dim_date[is_revenue_tracking_ok] = TRUE () ), CALCULATE ( COUNTROWS ( dim_date ), dim_date[is_revenue_tracking_ok] = TRUE () ) )
```

## Acquisition & attribution

| KPI | What it means | Caveat | Format |
|---|---|---|---|
| **Engagement Rate** | Engaged sessions ÷ sessions (GA4's engaged-session flag). |  | Percent, 1 dp |
| **Self-Referral Orders** | Orders whose converting session came from the store's own domain (customers back from the payment page). | A tracking artefact, not a channel; corrected attribution reassigns them. | Whole number |
| **Attributed Share** | Share of order credit per channel under each model; drives the seven-model heatmap. |  | Percent, 1 dp |
| **Orders (Naive Last Click)** | Last-click orders as GA4 reports them (self-referrals included). |  | Whole number |
| **Orders (Corrected Last Click)** | Last-click orders with self-referrals removed; journeys with no earlier visit are 'Unknown'. |  | Whole number |
| **Markov Share** | Data-driven (Markov chain) share of conversions per channel. | Covers the whole period: date filters don't apply. | Percent, 1 dp |
| **Markov 95% CI** | 95% bootstrap interval for the Markov share (200 resamples, fixed seed). |  | Text |
| **Organic Search Markov Share** | Organic Search's Markov share, for the KPI card. |  | Percent, 1 dp |
| **Single-Visit Order Share** | Share of orders whose journey has one visit, where every model gives the same answer. |  | Percent, 1 dp |
| **Session Share** | A country's share of sessions. |  | Percent, 1 dp |
| **Top 8 Country Share** | Session Share for the eight countries with the most sessions; blank for the rest. | Ranked within the current filters. | Percent, 1 dp |

**Markov 95% CI**

```dax

)
```

```dax
RETURN
    IF ( _rank <= 8, [Session Share] )
```

## Conversion & landing pages

| KPI | What it means | Caveat | Format |
|---|---|---|---|
| **Session to View Rate** | Sessions that viewed a product ÷ sessions. | Days with working cart tracking only (70 days). | Percent, 1 dp |
| **View to Cart Rate** | Sessions that added to cart ÷ sessions that viewed a product. The biggest leak. | 70 clean days. | Percent, 1 dp |
| **Cart to Checkout Rate** | Sessions that began checkout ÷ sessions that added to cart. | 70 clean days. | Percent, 1 dp |
| **Checkout to Purchase Rate** | Sessions that purchased ÷ sessions that began checkout. | 70 clean days. | Percent, 1 dp |
| **Funnel Sessions** | Sessions reaching the funnel step on the row (clean days). |  | Whole number |
| **Funnel Step Rate** | Share of the previous step that continued to this one. |  | Percent, 1 dp |
| **Desktop Step Rate** | Funnel Step Rate for desktop sessions only (Mobile Step Rate likewise). | Overrides the Device slicer on purpose. | Percent, 1 dp |
| **Mobile Minus Desktop** | Difference between the mobile and desktop step rates, in percentage points. |  | Text |
| **Mobile Minus Desktop CI** | 95% interval for that difference (normal approximation). | Every step's interval includes zero. | Text |
| **Session Purchase Rate** | Sessions with a purchase ÷ sessions, per landing page. |  | Percent, 2 dp |
| **Session Purchase Rate CI** | 95% Wilson interval for that rate. | Pages with fewer than 1,000 sessions are grouped as 'Other pages'. | Text |
| **Landing Session Share** | A landing page's share of all sessions. |  | Percent, 1 dp |

<details><summary>DAX for this page</summary>

**Session to View Rate**

```dax
DIVIDE ( [Sessions Viewed Product], [Funnel Base Sessions] )
```

**View to Cart Rate**

```dax
DIVIDE ( [Sessions Added to Cart], [Sessions Viewed Product] )
```

**Cart to Checkout Rate**

```dax
DIVIDE ( [Sessions Began Checkout], [Sessions Added to Cart] )
```

**Checkout to Purchase Rate**

```dax
DIVIDE ( [Sessions Purchased], [Sessions Began Checkout] )
```

**Funnel Sessions**

```dax
SWITCH (
    SELECTEDVALUE ( dim_funnel_stage[stage_order] ),
    1, [Funnel Base Sessions],
    2, [Sessions Viewed Product],
    3, [Sessions Added to Cart],
    4, [Sessions Began Checkout],
    5, [Sessions Purchased]
)
```

**Funnel Step Rate**

```dax
VAR _stage = SELECTEDVALUE ( dim_funnel_stage[stage_order] )
RETURN
    IF (
        _stage > 1,
        DIVIDE (
            [Funnel Sessions],
            CALCULATE ( [Funnel Sessions], REMOVEFILTERS ( dim_funnel_stage ), dim_funnel_stage[stage_order] = _stage - 1 )
        )
    )
```

**Desktop Step Rate**

```dax
CALCULATE ( [Funnel Step Rate], dim_device[device_category] = "desktop" )
```

**Mobile Minus Desktop**

```dax
VAR _d = [Mobile Step Rate] - [Desktop Step Rate]
RETURN
    IF ( NOT ISBLANK ( [Mobile Step Rate] ), FORMAT ( _d * 100, "+0.0;-0.0;0.0" ) & " pts" )
```

**Mobile Minus Desktop CI**

```dax
VAR _pm = [Mobile Step Rate]
VAR _pd = [Desktop Step Rate]
VAR _nm = CALCULATE ( [Step Base Sessions], dim_device[device_category] = "mobile" )
VAR _nd = CALCULATE ( [Step Base Sessions], dim_device[device_category] = "desktop" )
VAR _d = _pm - _pd
VAR _se = SQRT ( DIVIDE ( _pm * ( 1 - _pm ), _nm ) + DIVIDE ( _pd * ( 1 - _pd ), _nd ) )
RETURN
    IF (
        NOT ISBLANK ( _pm ),
        FORMAT ( ( _d - 1.96 * _se ) * 100, "+0.0;-0.0;0.0" ) & " to "
            & FORMAT ( ( _d + 1.96 * _se ) * 100, "+0.0;-0.0;0.0" ) & " pts"
    )
```

**Session Purchase Rate**

```dax
DIVIDE ( [Purchase Sessions], [Sessions] )
```

**Session Purchase Rate CI**

```dax
VAR _n = [Sessions]
VAR _k = [Purchase Sessions]
VAR _z = 1.96
VAR _p = DIVIDE ( _k, _n )
VAR _centre = ( _p + _z * _z / ( 2 * _n ) ) / ( 1 + _z * _z / _n )
VAR _half = _z * SQRT ( _p * ( 1 - _p ) / _n + _z * _z / ( 4 * _n * _n ) ) / ( 1 + _z * _z / _n )
RETURN
    IF ( _n > 0, FORMAT ( _centre - _half, "0.00%" ) & " to " & FORMAT ( _centre + _half, "0.00%" ) )
```

**Landing Session Share**

```dax
DIVIDE ( [Sessions], CALCULATE ( [Sessions], REMOVEFILTERS ( fct_sessions[landing_page_group] ) ) )
```

</details>

## Customers & retention

| KPI | What it means | Caveat | Format |
|---|---|---|---|
| **Customers** | Browsers (user_pseudo_id) with at least one order. | A person on two devices counts twice. | Whole number |
| **Repeat Customer Rate** | Customers who bought on 2+ different days ÷ customers. |  | Percent, 1 dp |
| **Median Customer Spend** | Median total spend per customer. |  | USD, whole |
| **Big Spender Revenue Share** | Share of customer revenue from the 'Big one-off spenders' segment. |  | Percent, 1 dp |
| **Back Within 14 Days** | Repeat buyers whose second buying day came within 14 days of the first ÷ repeat buyers. |  | Percent, 1 dp |
| **Share of Customers** | A segment's share of customers (Share of Revenue likewise for revenue). |  | Percent, 1 dp |
| **Repeat Within 30 Days** | Customers who bought again within 30 days ÷ customers who could be followed 30 days (7 and 14 likewise). | Blank when fewer than 100 customers could be followed that long. | Percent, 1 dp |
| **Eligible Customers 30 Days** | Customers whose first purchase was at least 30 days before 31 Jan. |  | Whole number |
| **Segment Action** | The suggested action for each segment, as text. |  | Text |

<details><summary>DAX for this page</summary>

**Customers**

```dax
COUNTROWS ( dim_customers )
```

**Repeat Customer Rate**

```dax
DIVIDE ( CALCULATE ( [Customers], dim_customers[buying_days] >= 2 ), [Customers] )
```

**Median Customer Spend**

```dax
MEDIAN ( dim_customers[revenue_usd] )
```

**Big Spender Revenue Share**

```dax
CALCULATE ( [Share of Revenue], dim_customers[rfm_segment] = "Big one-off spenders" )
```

**Back Within 14 Days**

```dax
DIVIDE ( CALCULATE ( [Repeat Buyers], dim_customers[days_to_repeat] <= 14 ), [Repeat Buyers] )
```

**Share of Customers**

```dax
DIVIDE ( [Customers], CALCULATE ( [Customers], REMOVEFILTERS ( dim_customers[rfm_segment] ) ) )
```

**Repeat Within 30 Days**

```dax
VAR _cut = DATE ( 2021, 1, 31 ) - 30
VAR _eligible = CALCULATE ( [Customers], KEEPFILTERS ( dim_customers[first_order_date] <= _cut ) )
RETURN
    IF (
        _eligible >= 100,
        DIVIDE (
            CALCULATE ( [Repeat Buyers], dim_customers[days_to_repeat] <= 30,
                        KEEPFILTERS ( dim_customers[first_order_date] <= _cut ) ),
            _eligible
        )
    )
```

**Eligible Customers 30 Days**

```dax
CALCULATE ( [Customers], KEEPFILTERS ( dim_customers[first_order_date] <= DATE ( 2021, 1, 1 ) ) )
```

**Segment Action**

```dax
SWITCH (
    SELECTEDVALUE ( dim_customers[rfm_segment] ),
    "Big one-off spenders", "Thank-you and a second-purchase offer within two weeks",
    "At risk", "One win-back email with a real reason to return",
    "Repeat, lapsing", "Personal note featuring their past categories",
    "Low-value one-offs", "No paid retargeting",
    "New customers", "Onboarding emails: the best chance of a second order",
    "Champions", "Early access and loyalty perks"
)
```

## Orders & products

| KPI | What it means | Caveat | Format |
|---|---|---|---|
| **Orders (Clean Value Days)** | Orders on days with recorded order values. | Excludes 26 to 31 Jan. | Whole number |
| **Median Order Value** | Median order value on days with recorded values. |  | USD, whole |
| **Mean Order Value** | Average order value on days with recorded values. | Pulled up by large orders; read with the median. | USD, whole |
| **Multi-Product Order Share** | Orders with 2+ different products ÷ orders with item detail. |  | Percent, 1 dp |
| **Top Decile Order Revenue Share** | Revenue from the top 10% of orders by value ÷ all revenue (clean days). |  | Percent, 1 dp |
| **Product Revenue** | Sum of item revenue (Units Sold, Product Orders likewise). |  | USD, whole |
| **Product Revenue Share** | A product's or category's share of all product revenue. |  | Percent, 1 dp |
| **Pair Orders** | Orders containing both products of a pair (pairs in 30+ orders only). | Full period, from mart_product_pairs. | Whole number |
| **Pair Lift** | How many times more often the pair is bought together than chance. |  | Number, 1 dp |

<details><summary>DAX for this page</summary>

**Orders (Clean Value Days)**

```dax
CALCULATE ( [Orders], dim_date[is_revenue_tracking_ok] = TRUE () )
```

**Median Order Value**

```dax
CALCULATE ( MEDIAN ( fct_orders[purchase_revenue_usd] ), dim_date[is_revenue_tracking_ok] = TRUE () )
```

**Mean Order Value**

```dax
CALCULATE ( [AOV], dim_date[is_revenue_tracking_ok] = TRUE () )
```

**Multi-Product Order Share**

```dax
DIVIDE (
    CALCULATE ( [Orders], fct_orders[basket_type] = "Several products" ),
    CALCULATE ( [Orders], fct_orders[basket_type] <> "No item detail" )
)
```

**Top Decile Order Revenue Share**

```dax
VAR _orders = CALCULATETABLE ( fct_orders, dim_date[is_revenue_tracking_ok] = TRUE () )
VAR _top = TOPN ( INT ( COUNTROWS ( _orders ) * 0.1 ), _orders, fct_orders[purchase_revenue_usd], DESC )
RETURN
    DIVIDE ( SUMX ( _top, fct_orders[purchase_revenue_usd] ), SUMX ( _orders, fct_orders[purchase_revenue_usd] ) )
```

**Product Revenue**

```dax
SUM ( fct_order_items[item_revenue_usd] )
```

**Product Revenue Share**

```dax
DIVIDE (
    SUM ( fct_order_items[item_revenue_usd] ),
    CALCULATE ( SUM ( fct_order_items[item_revenue_usd] ),
                REMOVEFILTERS ( fct_order_items[item_name], fct_order_items[item_category] ) )
)
```

**Pair Orders**

```dax
SUM ( mart_product_pairs[orders_together] )
```

**Pair Lift**

```dax
SUM ( mart_product_pairs[lift] )
```

</details>
